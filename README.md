# OptiMode — Community Credits

**Your participation. Your choice.**

OptiMode is a Future-by-Fie concept for an **optional (ON/OFF) Community Credits layer** in social platforms. Participating users could receive a share of value attributed to eligible community contributions. The concept proposes a **70% user / 30% platform** allocation of the credits generated by an eligible action.

## Status
**Runnable concept demo, not a live rewards or payment product.** All credits are fictional. No user accounts, tracking, monetization, wallet, cash-outs, payment processing, advertising attribution or third-party integrations exist.

## Try it locally
Requires Node.js 20 or newer.

```sh
npm install
npm run dev
npm test
npm run build
```

Open the local URL printed by Vite. Alternatively run `npm run preview` after building.

## What is implemented
- Community Credits switch, **OFF by default**.
- Slider simulating eligible actions, using synthetic values.
- Deterministic 70/30 allocation with integer credits.
- Automated tests for allocation, opting out and invalid input.
- Responsive, accessible single-page concept demonstration.

## Proposed user journey
1. Social-platform user sees the optional Community Credits setting.
2. User actively enables it; opting out yields zero credits.
3. A future trusted platform service verifies eligible activity and calculates value.
4. Credits are allocated 70% to user and 30% to platform.
5. Any future redemption or financial value requires separate legal, fraud and payment review.

## What is *not* implemented
The demo does not measure contribution value, prevent fraud, distribute money, prove fairness, persist balances or connect to any social network. It is not a token, cryptocurrency or investment product.

## Engineering approach
`src/credits.mjs` contains the small, testable calculation model. `src/main.mjs` renders the interactive demo. No secrets or external services are required. The workflow in `.github/workflows/quality.yml` runs tests and a production build.

## Future decisions

- Define whether credits are non-transferable points, redeemable rewards or monetary value.
- Evaluate creator incentives, fraud prevention, transparency and platform economics.
- Review applicable consumer, tax, payments, privacy and platform rules before handling real users or value.
